# Инструкции по публикации обновлений

## Настройка системы обновлений

### 1. Настройка GitHub репозитория

В `package.json` обновите настройки публикации:

```json
"publish": {
  "provider": "github",
  "owner": "ваш-username",
  "repo": "fastloader"
}
```

### 2. Создание GitHub токена

1. Перейдите в GitHub Settings → Developer settings → Personal access tokens → Tokens (classic)
2. Создайте новый токен с правами `repo`
3. Сохраните токен в безопасном месте

### 3. Установка зависимостей

```bash
npm install
```

Это установит `electron-updater`, который необходим для автоматических обновлений.

## Публикация обновлений

### Шаг 1: Обновите версию

В `package.json` измените версию:

```json
"version": "1.0.1"
```

### Шаг 2: Создайте релиз на GitHub

1. Создайте новый релиз на GitHub:
   - Перейдите в ваш репозиторий
   - Нажмите "Releases" → "Create a new release"
   - Укажите версию (например, `v1.0.1`)
   - Добавьте описание изменений
   - Нажмите "Publish release"

### Шаг 3: Соберите приложение

```bash
npm run build
```

Это создаст файлы в папке `dist/`.

### Шаг 4: Опубликуйте обновление

Для автоматической публикации на GitHub:

```bash
# Установите GitHub токен как переменную окружения
export GH_TOKEN=ваш_github_токен

# Опубликуйте
npm run build -- --publish always
```

Или вручную загрузите файлы из `dist/` в релиз на GitHub.

## Как работает система обновлений

1. **При запуске приложения:**
   - Через 3 секунды после запуска автоматически проверяются обновления
   - Если обновление найдено, показывается модальное окно

2. **Проверка обновлений вручную:**
   - В настройках есть кнопка "Проверить обновления"
   - При нажатии открывается модальное окно с результатом

3. **Процесс обновления:**
   - Пользователь видит доступное обновление
   - Может загрузить обновление
   - Видит прогресс загрузки
   - После загрузки может установить обновление
   - Приложение перезапустится с новой версией

## Альтернативные провайдеры

Вместо GitHub можно использовать:
- **Generic** - любой HTTP сервер
- **S3** - Amazon S3
- **Spaces** - DigitalOcean Spaces
- **Bintray** - JFrog Bintray

Пример для Generic провайдера:

```json
"publish": {
  "provider": "generic",
  "url": "https://your-server.com/updates"
}
```

## Важные замечания

1. Обновления работают только в собранном приложении (не в режиме разработки)
2. Для Windows нужен код-подпись для автоматических обновлений (опционально)
3. Убедитесь, что версия в `package.json` всегда увеличивается
4. Файлы обновлений должны быть доступны по HTTPS
